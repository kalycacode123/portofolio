Belajar Membangun Website dari Dasar

Halo! Nama saya Kalyca Suganda. Saya adalah mahasiswa S1 Teknik Informatika di Universitas Negeri Surabaya (UNESA) angkatan 2026 yang berasal dari Palembang, Sumatera Selatan.

Website portofolio ini saya bangun untuk memenuhi tugas mata kuliah pemrograman web. Melalui tugas ini, saya belajar menyusun struktur halaman dengan HTML5 semantik, menata tata letak dengan CSS murni, serta menambahkan interaktivitas sederhana menggunakan JavaScript.

Sebagai mahasiswa yang masih dalam tahap awal belajar, saya menyadari web ini masih sederhana dan terus membutuhkan perbaikan. Saya sangat terbuka untuk menerima kritik, saran, serta bimbingan dari dosen maupun teman-teman agar pemahaman pemrograman saya dapat terus meningkat.
